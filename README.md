# Global Interior Group

Сайт компании: сантехника и котлы. Один файл `index.html`, без сборки.

## Публикация на GitHub Pages
1. Загрузите `index.html` и `README.md` в корень репозитория.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.
